# Asteroids
Asteroids game developed in C++ using the openFrameworks open-source toolkit. Completed as a midterm project for CS 134 w/ Professor Kevin Smith @ San Jose State University. Originally published October 28, 2025. Last modified Nov. 2, 2026.

## Controls

- W to boost forward
- A to turn left
- S to boost backward
- D to turn right
- Space to shoot
- R to reset game
